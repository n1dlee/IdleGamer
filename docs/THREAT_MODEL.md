# THREAT_MODEL (STRIDE)

## 1. Активы

| # | Актив | Ценность | Где живёт |
|---|---|---|---|
| A1 | Steam refresh token (JWT, ~долгоживущий) | **Критическая**: даёт вход в CM-сессию без пароля и 2FA до отзыва | Vault (AES-GCM, Keystore), RAM `SteamSessionManager` |
| A2 | Access token | Высокая, короткая жизнь | Только RAM, не сохраняется |
| A3 | Активная CM-сессия | Высокая | Процесс приложения |
| A4 | SteamID64 / account name | Средняя (PII, упрощает фишинг) | Vault (account name), Room/DataStore (SteamID для UI) |
| A5 | Кэш библиотеки игр | Низкая | Room |
| A6 | Настройки | Низкая | DataStore |
| A7 | Журнал событий | Низкая–средняя (временные метки активности) | Room (`event_log`), без секретов |
| A8 | Ключ шифрования vault | Критическая (эквивалент A1) | Android Keystore (TEE/StrongBox), неэкспортируемый |
| A9 | Целостность APK | Высокая | Подпись APK |
| A10 | QR challenge URL | Высокая в течение жизни QR: кто его отсканирует и подтвердит — получит сессию… **но подтверждает владелец**, поэтому реальный риск — социальная инженерия | RAM, экран |

| ID | Нарушитель | Возможности |

| T2 | Физический доступ к разблокированному устройству | UI, adb (если включён), скриншоты |

| T5 | Сетевой злоумышленник | MITM Wi-Fi, DNS-спуфинг |

## 4. Обычное vs rooted устройство

* **Обычное устройство (FBE, без root):** песочница + Keystore (TEE) + отсутствие backup делают извлечение токена непрактичным без эксплойта ОС.
* **Rooted / скомпрометированное:** Keystore **не защищает** от злоумышленника, контролирующего процесс приложения: ключ нельзя вытащить, но им можно воспользоваться. Злоумышленник с root может также читать память процесса (токен в RAM во время сессии). Рекомендация: не использовать IdleGamer на rooted устройствах с непроверенными модулями; при подозрении — «Deauthorize all devices» в Steam.

## 5. Ущерб при компрометации refresh token (R10)

* Злоумышленник может войти в CM-сессию (чат, presence, библиотека, покупки с сохранённым способом оплаты через клиент? — **да, клиентская сессия Steam способна инициировать покупки с кошелька**), но **не** может сменить пароль/почту без 2FA.
* Действия: Logout в IdleGamer (best-effort `revokeToken`), затем на <https://store.steampowered.com/twofactor/manage> → «Deauthorize all other devices», смена пароля.
