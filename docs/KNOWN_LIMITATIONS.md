# KNOWN_LIMITATIONS

## Не подтверждено на реальном аккаунте

* Весь путь после одобрения QR: логон, `GetOwnedGames`, presence, `RevokeToken`, продление токена. Реализовано по API JavaSteam 1.8.0 и протестировано на fake-транспорте; на реальном Steam проверено только получение QR-челленджа и CM-соединение.
* Засчитывает ли Steam время presence — неизвестно и не может быть подтверждено мгновенно (нет ack).
* Присылает ли Steam `PersonaStateCallback` для собственного аккаунта (для «эха» presence) — не проверено.
* Поведение при одновременной сессии десктопного клиента с другим `loginId` — не проверено.

## Ограничения протокола / Steam

* Максимум 32 игры одновременно.
* Нет подтверждения presence; локальный таймер — не доказательство.
* `RevokeToken` может быть отклонён Steam — тогда нужен ручной отзыв.
* Протокол может измениться без уведомления (R1).
* Список игр — owned, а не установленные; free-to-play без игрового времени может отсутствовать (`include_played_free_games` возвращает только сыгранные).

## Ограничения Android

* Без wake lock CPU может уснуть при выключенном экране → Steam разорвёт сессию → Reconnecting. Не измерено на реальном устройстве.
* OEM-оптимизаторы батареи могут убивать процесс.
* Нет автозапуска после reboot (сознательно).
* targetSdk 36 (Android 16): на Android 17 работает в режиме совместимости; поведение не проверено.

## Заблокировано сознательно

Парольный вход, ввод/генерация Steam Guard кодов, shared/identity secret, автоматизация карточек и badges,
трейды/маркет/инвентарь, изменение профиля и статуса, маскировка клиента, обход античита.

## Технический долг

* Локализация: только английский интерфейс (документация на русском).
* Нет baseline profile и macrobenchmark.
* `DataStoreSettingsRepository` хранит SteamID последнего аккаунта (не секрет) для обнаружения смены аккаунта.
* Room-миграций пока нет (версия схемы 1); каждая следующая версия обязана добавить миграцию и тест.
* Debug-сборка подписывается стандартным debug-ключом SDK; release-подпись — забота владельца.
