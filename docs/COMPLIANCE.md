# COMPLIANCE — правила Steam, риски для аккаунта, лицензии

> **Кратко:** использование presence для накопления часов, по тексту Steam Subscriber
> Agreement (ревизия от 2026-09-10), является нарушением §4.C. IdleGamer не скрывает
> это от пользователя и не содержит механизмов маскировки. Решение о применении —
> исключительно на владельце аккаунта.

## 1. Steam Subscriber Agreement (SSA), ревизия 2026-09-10

Источник: <https://store.steampowered.com/subscriber_agreement/> (прочитано 2026-10-17).

| Раздел | Суть (пересказ) | Отношение к IdleGamer |
|---|---|---|
| §4.C | Запрещены скрипты, боты, макросы и иные «non-human-controlled systems» для взаимодействия с контентом Steam, в т.ч. **фальсификация игровой статистики, включая playtime**, и получение наград/прогресса без реального участия пользователя. Цитата: “You may not use any form of scripts, bots, macros, or other non-human-controlled systems” | Presence без запущенной игры = формально «faking … playtime». **Прямой риск.** Получение карточек без игры = «rewards without genuine input» |
| §4.B | Запрещено стороннее неавторизованное ПО, изменяющее процессы маркетплейса/интерфейсы Steam; запрещён обход античита | IdleGamer не трогает маркетплейс, античит, игровые процессы |
| §4.D | Valve применяет автоматическое обнаружение и ручную проверку; может ограничить или закрыть аккаунт без предупреждения | Санкции возможны без уведомления |
| §9.C | Ограничения за нарушения — без возврата средств кошелька | Финансовый риск |
| §1.C, §3.B | Логин/пароль нельзя передавать третьим лицам | IdleGamer не запрашивает пароль вообще; токен остаётся на устройстве |
| §3.A | Сокрытие места проживания через прокси → закрытие доступа | IdleGamer не использует прокси/VPN |

### Возможные санкции (по SSA)
Ограничение отдельных функций, приостановка или закрытие аккаунта, без предварительного
уведомления и без возврата средств. SSA не упоминает VAC/игровые баны поимённо; VAC
относится к античиту в играх, которых IdleGamer не касается.

## 2. Presence ≠ реальная игра

* Сообщение `ClientGamesPlayed` не запускает игру, не исполняет её код, не даёт достижений.
* Друзья видят «В игре: X», что не соответствует действительности — пользователь должен это понимать.
* Локальный таймер IdleGamer показывает только **длительность локальной сессии**. Засчитал ли Steam часы — видно только по `playtime_forever` после повторной загрузки (и с задержкой).

## 3. Карточки и достижения

* IdleGamer **не** реализует сбор карточек: не парсит страницу значков, не переключает игры автоматически по количеству оставшихся дропов, не продаёт и не обменивает предметы.
* Достижения не могут быть получены через presence и IdleGamer их не трогает.
* Условия выпадения карточек определяются Valve и могут меняться без уведомления.

## 4. Чего IdleGamer принципиально не делает (non-goals, зафиксировано в коде ревью)

* Нет маскировки: имя устройства в Steam = `IdleGamer (<модель>)`, ОС = Android (как определяет JavaSteam). Нет подмены идентичности официального клиента, ротации IP, случайных задержек «под человека».
* Нет обхода античита, Steam Guard, rate limits.
* Нет трейдов, маркета, инвентаря, подтверждений мобильного аутентификатора, изменения профиля/статуса.
* Нет запуска без явного действия пользователя (Start), нет автостарта после перезагрузки.
* Нет сервера, облака, аналитики.

Если функция невозможна без перечисленного — она помечена в KNOWN_LIMITATIONS.md как заблокированная.

## 5. Отсутствие гарантий

Valve не поддерживает сторонние клиенты. Протокол может измениться в любой момент (R1),
сессия может быть разорвана, методы — удалены. IdleGamer показывает фактическое
состояние и не симулирует успех.

## 6. Пользовательское согласие в приложении

Перед первым Start приложение показывает диалог рисков (SSA §4.C, возможные санкции,
presence ≠ игра) и требует явного подтверждения. Факт подтверждения хранится локально
в DataStore (не секрет) и может быть сброшен в настройках.
